## Featured projects

### Full-stack & backend

- **[YourHome / Tounes Abroad](https://github.com/IhebKhalfallaah/YourHome_Backend)**: Community platform for Tunisians abroad. Spring Boot 4 modular monolith (20 domain modules, 28 ADRs, Keycloak, STOMP live updates, LiveKit audio) with a React + TypeScript web app ([frontend](https://github.com/IhebKhalfallaah/YourHome)) and an Expo mobile app.
- **[Kafka Streams Offer Arena](https://github.com/IhebKhalfallaah/kafka-streams-offer)**: Real-time trading pipeline. Kafka Streams scores offers with exactly-once processing and KStream/KTable joins, then streams live to a React dashboard through Spring Boot SSE.

### Applied AI services

- **[NERA: Arabic NER](https://github.com/IhebKhalfallaah/NERA)**: FastAPI service that serves a fine-tuned XLM-RoBERTa model to tag people, places and organizations in Arabic text (overall F1 0.80). Dockerized and tested.
- **[Parking Dynamic Pricing](https://github.com/IhebKhalfallaah/PricePredictionSystem)**: CNN-LSTM + XGBoost forecast of car-park occupancy, turned into a 7-day × 24-hour price grid by a FastAPI REST API.
- **[Tunisian Licence Plate Recognition](https://github.com/IhebKhalfallaah/tunisianlicenceplate)**: Flask app that detects, reads (ONNX CNN + YOLOv5 + EasyOCR) and blurs Tunisian plates, with results stored in MySQL.
- **[HeartScan AI: ECG ischemia](https://github.com/IhebKhalfallaah/ECG-Signal-Prediction-)**: 2-lead ECG pipeline (Butterworth filters, Pan-Tompkins, entropy features, SVM) behind a Flask web app.

### Research

- **[Railway Fault Diagnosis](https://github.com/IhebKhalfallaah/Machine-Learning-Based-Railway-Fault-Diagnosis)**: Three-stage hierarchical ML cascade over 7 vibration channels and 10 health states (84.2 % end-to-end accuracy). Paper under review.
- **[HMA-DRL: Fog computing](https://github.com/IhebKhalfallaah/CHM-Application-RL)**: Hierarchical multi-agent DQN/A2C for microservice placement and task offloading on iFogSim2 (96–98 % emergency QoS). Paper under review.
